# 🎨 EmirPx the Pixel Art Editor

A lightweight, intuitive, and feature-rich Pixel Art creation tool designed for quick sketching, palette management, and image editing.

Whether you're creating retro game assets, crafting custom color palettes, or doodling over existing photos, this application provides a clean, clutter-free workspace to bring your pixel ideas to life.

## ✨ Key Features

* 🎨 **Dynamic Palette Customization**
  * Create, modify, and manage custom color palettes on the fly.
  * Add or remove colors with a single click.
  * Switch active drawing colors seamlessly while working.

* 🖌️ **Flexible Canvas & Export**
  * Draw pixel art effortlessly with responsive grid controls.
  * Export and download your finished artwork directly to your device in PNG format.

* 🖼️ **Image Import & Overlay**
  * Import any existing image directly onto the canvas.
  * Draw, annotate, or sketch pixel art over imported photos.
  * Ideal for tracing, retro-style editing, or creative improvisations.

* ⚡ **Fast & Distraction-Free**
  * Clean UI focused purely on simplicity and productivity.
  * Minimalist workflow without overwhelming menus or unnecessary clutter.

## 💡 How to Use

1. **Set Up Your Palette:** Add your favorite colors to the palette panel or remove unused ones.
2. **Start Painting:** Pick a color, select your brush size, and start placing pixels on the grid.
3. **Import Base Image:** Click the **Import** button to load a background image and doodle over it.
4. **Save Artwork:** Click **Export / Download** to save your pixel creation to your computer.

## 🛠️ Built With

* **HTML5 Canvas API** - Core rendering engine
* **CSS3** - Responsive styling & UI layout
* **JavaScript (ES6+)** - Interactivity and state management
